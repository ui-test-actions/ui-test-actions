The initial external harness showed two adoption gaps. A privileged bridge lost the Python import path when `sudo` launched it, and a WireGuard postflight check replaced that path. The consumer fixed both integrations by passing the public checkout path explicitly. The Action SHA did not change. [Initial mobile harness failure](https://github.com/ui-test-actions/ui-test-actions-consumer-acceptance/actions/runs/44842594209) · [Initial WireGuard postflight failure](https://github.com/ui-test-actions/ui-test-actions-consumer-acceptance/actions/runs/44842594185)

The [five-platform 60-minute and cancellation evidence](../v2/lifetime/) uses its recorded earlier Action pin. The independent consumer and Named runs above use shorter sessions to verify the current transport paths. The reports distinguish the two sets of pins and lease lengths.

The evidence audit checked retained files and public workflow logs for known generated credentials. It found no matches and no private-key blocks in the retained files. [Audit totals](credential-audit.json)

The private transport was exercised with WireGuard. A Tailscale enrollment and its ACL or identity configuration need a test tailnet. The hosted mobile run covers IPv4 LAN mDNS and secure-v2 with the upstream samples. Physical radios, physical keyboard composition, and additional hosted iOS backend and image combinations have separate acceptance requirements. Interactive Cloudflare Access sign-in for the embedded browser needs its own configured user policy. The Named results below cover Service Auth for external automation, and the browser inspector evidence above uses Quick Tunnel. ## Cloudflare Named Tunnel

The initial synthetic-origin check reached the loopback service with both missing and invalid Access credentials. The Cloudflare account had no matching Access application. An exact-host self-hosted application for `uitest.abdelrahmanfahmy.dev` now requires one scoped Service Auth policy. The protected retry at the original pin still failed closed before publishing. With the same origin and credentials, curl passed over HTTP/1.1 and HTTP/2, and both curl and Python reproduced Cloudflare error 1010 when using Python's default identifier. The corrected Named client uses its product identifier and retains the Service Auth and UI bearer checks. [Initial client failure](https://github.com/ui-test-actions/ui-test-actions/actions/runs/44842056936) · [Hosted HTTP comparison](https://github.com/ui-test-actions/ui-test-actions/actions/runs/44845796403) · [Redacted results](cloudflare/http-client-comparison.json) · [Cross-platform regression](https://github.com/ui-test-actions/ui-test-actions/actions/runs/44845982953)

The external hosted observer changed the fixture's blue status to green. A fresh client identified the same session, saw the same UI, and received the cached response to a repeated request ID. The host separately asserted one exact Unicode submission. Missing Access headers returned 403, an invalid service secret returned 401, missing and wrong UI bearers returned 401, and a mismatched session ID returned 409. All 63 authenticated stability samples before expiry returned HTTP 200. The final live response showed zero seconds remaining, followed by HTTP 530 twice. A second same-host connector stayed pending with zero running jobs and was cancelled before it could connect. [Host](https://github.com/ui-test-actions/ui-test-actions/actions/runs/44845998583) · [External observer](https://github.com/ui-test-actions/ui-test-actions/actions/runs/44846047122) · [Visual and time evidence](cloudflare/expiry/) · [Concurrency evidence](cloudflare/concurrency.json)

The cancellation observer completed a separate visual journey and submitted cancellation during an eight-minute lease. The last HTTP 200 arrived at +13.527 seconds with 460 seconds remaining. The first HTTP 502 arrived at +15.583 seconds and another at +17.675 seconds. GitHub marked the host run cancelled. [Host](https://github.com/ui-test-actions/ui-test-actions/actions/runs/44846275003) · [External observer](https://github.com/ui-test-actions/ui-test-actions/actions/runs/44846396608) · [Timing and UI evidence](cloudflare/cancellation/)
